<div data-lang="zh" markdown="1">

我的macOS 发布首个公开版本 **0.1.0**。它把系统状态、应用、存储、网络与定时任务收进一个窗口：

- 实时 CPU、内存、Swap、磁盘 I/O、网络与温度监控，支持阈值告警
- 应用清单、运行状态与打开 / 重启 / 强停 / 卸载
- 存储分类、大文件与缓存清理
- 按应用聚合的外联 / 入站连接与 Clash/Mihomo 代理透视
- LaunchAgent、LaunchDaemon 与 Crontab 统一管理

0.1.0 已完成 Developer ID 签名并通过 Apple 公证，可直接从 [GitHub Releases](https://github.com/petterobam/device-operate/releases/latest) 下载。当前构建面向 Apple Silicon，要求 macOS 13 或更高版本；需要完全磁盘访问或自动化权限的功能会在应用内明确提示。

更多界面与安装说明见 [我的macOS 应用页](/apps/my-macos/)。

<div data-lang="en" markdown="1">

My macOS 0.1.0 is the first public release, bringing system health, apps, storage, network, and scheduled tasks into one window:

- Real-time CPU, memory, swap, disk I/O, network, and temperature monitoring with alerts
- App inventory, running state, and open / restart / force quit / uninstall
- Storage categories, large files, and cache cleanup
- Per-app outbound and inbound connections with Clash/Mihomo proxy awareness
- LaunchAgents, LaunchDaemons, and crontab entries in one place

Version 0.1.0 is Developer ID signed and notarized by Apple, and is available from [GitHub Releases](https://github.com/petterobam/device-operate/releases/latest). This build targets Apple Silicon and requires macOS 13 or later; features that need Full Disk Access or Automation explain the permission in the app.

See the [My macOS app page](/apps/my-macos/) for screenshots and installation notes.
