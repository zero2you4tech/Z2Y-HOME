<div data-lang="zh" markdown="1">

Z2Y 目标在 App Store 更新至 **2.0.0**。这一版把方向、行动和习惯收进同一个系统：目标按「目标 → 子目标 → 行动」三层拆解，行动被安排到今天；习惯从身份认同出发，用触发线索和两分钟版本维持，并在错过之后给出恢复路径，而不是清空连续天数。

数据继续保存在本机 SQLite 中，不需要账号：可以导出带逐文件 SHA-256 校验的 ZIP 包，也可以导入旧版导出包。iOS 上还有系统提醒、今天 Widget 与专注会话的实时活动，本次同时优化了行动日期布局与目标、习惯页面文案。

界面预览、使用步骤与常见问题见 [Z2Y 目标使用说明](/support/z2y-goals-plus/)，当前版本与系统要求可以在 [应用目录](/apps/z2y-goals-plus/) 查看。

<div data-lang="en" markdown="1">

Z2Y Goals is now at **2.0.0** on the App Store. This release brings direction, action, and habits into one system: a goal is broken down as goal → subgoal → action, actions are scheduled into today, and habits start from an identity, are held up by cues and a two-minute version, and offer a recovery path after a miss instead of resetting the streak.

Data stays in a local SQLite database with no account required: export a ZIP with per-file SHA-256 hashes, or import packages from the earlier version. On iOS the app also brings system reminders, a Today widget, and Live Activities for focus sessions, and this release refines the action date layout plus the copy on goal and habit screens.

See the [usage guide](/support/z2y-goals-plus/) for interface previews, step-by-step instructions, and troubleshooting, or open the [app catalog](/apps/z2y-goals-plus/) for the current version and requirements.
